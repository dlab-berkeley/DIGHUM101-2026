## Exercise 10: Viewing Your Markdown File

Markdown files are written as plain text, but they can also be rendered into formatted documents.

To preview your file in VS Code:

- Click the preview icon in the upper-right corner of the editor

- Or press:

  - `Shift + Command + V` (Mac)

  - `Shift + Ctrl + V` (Windows)

This will open a formatted preview of your Markdown file.
